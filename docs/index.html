What is FireLab?

FireLab replaces the Firebase CLI with a modern web dashboard. Instead of running firebase emulators:start in terminal, you get:

✅ Visual project management
✅ One-click emulator control
✅ Automatic data snapshots
✅ Built-in rules & indexes editor
✅ Real-time log streaming
✅ Remote access support
✅ Fetch & deploy to production
✅ JWT-secured web interface
✅ Configurable host binding
✅ Rules tester (ALLOW/DENY simulation)
✅ Version history (last 20 versions)
✅ Persistent logs across reloads

Firebase CLI vs FireLab

🔥 Firebase CLI

  • ❌ Terminal commands only
  • ❌ No data persistence
  • ❌ Manual snapshot management
  • ❌ Basic text editor for rules
  • ❌ Logs mixed with terminal output
  • ❌ Local machine only
  • ❌ No project templates
  • ❌ No visual indexes management

🚀 FireLab

  • ✅ Beautiful web interface
  • ✅ Auto-snapshots every 15min
  • ✅ One-click restore/backup
  • ✅ VS Code editor with syntax highlighting
  • ✅ Real-time filtered logs
  • ✅ Remote backend support
  • ✅ Project templates & seed data
  • ✅ Indexes editor & production sync

😫 "I lost all my test data"

Emulator restarts = data gone

→ Auto-snapshots every 15min + manual backups

😩 "Terminal commands are tedious"

Typing firebase commands repeatedly

→ One-click start/stop with Ctrl+E shortcut

😵 "Rules editing is painful"

No syntax highlighting, no autocomplete

→ VS Code editor with validation & history

😐 "Logs are messy"

Mixed with terminal output, hard to filter

→ Clean real-time logs with service filtering

😤 "Can't share with team"

Everyone needs local setup

→ Remote backend - share one emulator instance

😭 "Setting up test data takes forever"

Manual data entry every time

→ Seed scripts + snapshot restore in seconds

😰 "Managing indexes is a guessing game"

No visual editor, manual JSON editing

→ Visual indexes editor with validation & production sync

😬 "Syncing rules with production is risky"

Copy-pasting between console and local files

Powerful Features

🚀

One-Click Start

Start and stop Firebase emulators with a single click. No command line needed.

📸

Smart Snapshots

Auto-snapshots every 15 minutes. Create, restore, and download snapshots instantly.

✏️

VS Code Editor

Edit security rules with Monaco Editor. Syntax highlighting, JSONC support, version history (last 20), and fetch from production.

📊

Real-Time Logs

Stream emulator logs in real-time with ANSI colors and service filtering.

🌱

Seed Data

Populate test data with custom Node.js scripts. Perfect for development workflows.

🐳

Docker Ready

Deploy anywhere with Docker. Pre-built images available on Docker Hub.

🔌

Remote Backend

Run emulators on a remote machine, access UI from anywhere on your network.

⚡

Keyboard Shortcuts

Ctrl+E to start/stop, Ctrl+L to clear logs, Ctrl+S to save. Work faster.

🔐

Secure Authentication

JWT-based authentication system to secure your emulator management interface.

🔧

Port Conflict Detection

Automatic port conflict detection with smart suggestions and auto-fix capabilities.

📱

Mobile Responsive

Works perfectly on mobile devices. Manage emulators from anywhere, anytime.

🧪

Rules Tester

Simulate ALLOW/DENY operations with custom path, operation, and auth UID before deploying.

📇

Indexes Editor

Edit, validate, and deploy Firestore composite indexes. Fetch production indexes with one click.

📋

Copy & Share URLs

One-click copy of service URLs. Easy sharing with team members.

🔍

Debug Logging

Always-on debug logging with rotating log file. Filter by ALLOW, DENY, Rules, Reads, Writes, Errors and download the full log.

☁️

Production Sync

Fetch deployed rules and indexes from Firebase production. Deploy changes with one click.

🌐

Host Binding

Configure emulator host binding from the UI. Restrict to localhost or open to network.

💾

Persistent Logs

Logs persist across page reloads. Never lose important emulator output again.

Quick Start

🐳 Docker Hub (Easiest)

docker run -d \
  -p 3001:3001 \
  -p 4000-4010:4000-4010 \
  -p 5000-5010:5000-5010 \
  -p 8080-8089:8080-8089 \
  -p 9000-9010:9000-9010 \
  -p 9099-9109:9099-9109 \
  -p 9199-9209:9199-9209 \
  -v firelab-projects:/app/firebase-projects \
  --name firelab leobardo21/firelab:latest

📦 Docker Compose

git clone https://github.com/TwoZer00/FireLab.git
cd FireLab
docker-compose -f docker-compose.prod.yml up -d

💻 Local Install

git clone https://github.com/TwoZer00/FireLab.git
cd FireLab
npm run setup
npm run build
npm start
